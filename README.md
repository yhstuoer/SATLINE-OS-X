# SATLINE OS X

运行在 ESP32 微控制器上的轻量级图形操作系统，配备 TFT 彩色屏幕，提供时钟、计时器、秒表和游戏等实用功能。

## ✨ 核心特性

| 功能 | 说明 |
|------|------|
| 实时时钟 | 精确到秒的系统计时，带心跳动画 |
| 智能计时器 | 1-60分钟可调倒计时，进度圆环可视化 |
| 高精度秒表 | 毫秒级精度，支持启停/重置 |
| 互动游戏 | 方向控制吃方块，实时计分 |
| 流畅菜单 | 动画过渡效果，物理按键导航 |

## 🛠️ 硬件要求

- 主控：ESP32
- 屏幕：ST7735 1.8寸 TFT (128x160)
- 母座：15×1、12×1 各一个

## 🔌 接线

| TFT | ESP32 |
|-----|-------|
| MOSI | GPIO 23 |
| SCLK | GPIO 17 |
| CS | GPIO 15 |
| DC | GPIO 2 |
| RST | GPIO 4 |

## 📦 安装

1. 安装 Arduino IDE
2. 安装 ESP32 开发板支持
3. 安装 TFT_eSPI 库
4. 上传代码
